📄 How to Export This as a Canva-Editable PDF

  1. Click the "Save as PDF" button below (or press Ctrl+P)
  2. In the print dialog, set Destination → "Save as PDF"
  3. Set Layout → Landscape and Paper Size → A3
  4. Enable "Background graphics" under More Settings
  5. Click Save, then go to canva.com → Create a Design → Import File
  6. Upload the PDF — Canva will convert all text, shapes, and colors into fully editable elements!
